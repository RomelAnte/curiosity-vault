# Código de conducta

Curiosity Vault es un espacio para aprender y compartir conocimiento. Para que siga siendo así:

- Trata a los demás con respeto, incluso en desacuerdo.
- Da retroalimentación sobre el contenido o el código, no sobre la persona.
- No se tolera acoso, lenguaje discriminatorio ni ataques personales, en issues, pull requests o cualquier otro espacio del proyecto.

Si presencias o sufres una conducta que rompe estas reglas, repórtala abriendo un issue marcado como confidencial o contactando directamente a los mantenedores del repositorio.

Quien mantiene el proyecto puede eliminar comentarios, commits o contribuciones que no respeten este código, y en casos graves, bloquear temporal o permanentemente a quien los cometa.
