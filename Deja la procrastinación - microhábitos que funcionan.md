Dejar de procrastinar

**Descripción:**
Técnicas prácticas para reducir la procrastinación: mejorar el entorno, usar listas y temporizadores, crear micro-hábitos y eliminar distracciones.

**Categoría:** Productividad / Hábitos

**Tags:** procrastinación, productividad, hábitos, enfoque, micro-hábitos

**Fuente:** Videos de TikTok (varios creadores)

**Fecha de descubrimiento:** 2026-08-29

**¿Por qué me pareció interesante?:**
Ofrece pasos concretos y fáciles de implementar para empezar a actuar hoy mismo.

**¿Lo quiero probar?:** Sí — implementar micro-hábitos y usar temporizadores.

---

## Puntos clave
- Limpiar y simplificar el espacio de trabajo.
- Evitar el celular y cerrar pestañas irrelevantes.
- Usar lista de tareas y temporizador (Pomodoro/intervalos).
- Crear una lista de malos hábitos para reemplazarlos por nuevos hábitos.
- Aceptar el punto de partida, soltar el pasado y rodearse de energía de crecimiento.
