# De idea a MVP: construir para aprender

Una idea no necesita estar terminada para ponerse a prueba. Un MVP sirve para aprender con personas reales antes de invertir demasiado tiempo o dinero.

## El ciclo

1. **Construir:** crea la versión más pequeña que permita comprobar una suposición importante.
2. **Medir:** observa qué hacen las personas, qué entienden y qué problema aparece.
3. **Aprender:** decide qué conservar, cambiar o descartar antes del siguiente ciclo.

## Documento mínimo del proyecto

- Nombre, objetivo, propósito y fecha.
- Problema, usuario y resultado esperado.
- Alcance: qué incluye la primera versión y qué queda fuera.
- Personas involucradas: usuarios, cliente, proveedores y equipo.
- Funcionalidades priorizadas, páginas y navegación.
- Cronograma corto con reuniones y sprints.
- Riesgos y una posible respuesta para cada uno.

Lean Startup define este ciclo como construir una experiencia suficiente para obtener información, medir la reacción de clientes y usar los resultados para orientar el siguiente experimento. [Principios de Lean Startup](https://leanstartup.co/about/principles/)

## Ejercicio

Escribe una hipótesis con esta fórmula: “Creemos que **[tipo de persona]** tendrá el problema **[problema]** y probará **[solución mínima]**”. Después, define qué señal observarás para saber si vale la pena continuar.
