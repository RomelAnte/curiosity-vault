# Cómo ser visible en redes sociales

## Apuntes de partida

- Pedir una campaña: producto, cliente, problema y beneficio.
- Crear cinco piezas conectadas:
  - reel para llamar la atención;
  - carrusel para explicar;
  - historia para recordar;
  - WhatsApp para vender;
  - correo para cerrar.

## Aporte editorial

La secuencia funciona como un recorrido: atraer, explicar, mantener el interés y facilitar una conversación. Antes de publicar, formula una sola propuesta: “Ayudo a **[cliente]** que tiene **[problema]** a obtener **[beneficio]** con **[producto o servicio]**”.

## Ejercicio

Elige una oferta y escribe una idea para cada una de las cinco piezas. Todas deben hablar del mismo problema.

## Créditos

- **Punto de partida:** apunte personal local “## Como ser visible en redes social.txt”.
- **Aporte editorial:** estructura y ejemplo de aplicación.
