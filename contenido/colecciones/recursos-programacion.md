# Recursos para programación y ciberseguridad

Lista de recursos reunidos en los apuntes. Comprueba su disponibilidad, propósito y condiciones antes de usarlos.

## Programación

- [CodePen](https://codepen.io/): experimentar y compartir fragmentos de código web.
- [OverAPI](https://overapi.com/): colección de hojas de referencia rápida; verifica la documentación oficial para confirmar detalles de cada tecnología.
- [Clean Code JavaScript](https://github.com/ryanmcdermott/clean-code-javascript): guía comunitaria con recomendaciones de estilo para JavaScript. Contrasta sus consejos con las convenciones y documentación de tu proyecto.

## Ciberseguridad

- [CheckPhish](https://checkphish.bolster.ai/): herramienta anotada para revisar sitios sospechosos. Un resultado automático no demuestra por sí solo que una página sea segura o maliciosa.
- Canales anotados: Contando Bits, Solo Python y The Cyber Mentor. Confirma los canales exactos y valora que el contenido sea legal y seguro para practicar.
- `tripledobleu.online` aparece en la nota como página para aprender ciberseguridad; verifica su identidad, contenido y seguridad antes de abrirla o confiar en ella.
