# Frases populares y trucos de trabajo

Una colección de recordatorios personales. Los atajos pueden variar según la aplicación, el sistema operativo y la configuración.

## Atajos anotados

- **Alt + Shift + F:** formato de código en algunos editores.
- **Ctrl + P:** abrir o buscar archivos en muchos editores.
- **Ctrl + Shift + P:** abrir la paleta de comandos.
- **Ctrl + K, luego Ctrl + C:** comentar la selección en algunas herramientas.
- **Alt + ↑ / Alt + ↓:** mover una línea o selección en ciertos editores.
- **Ctrl + Alt + ↓:** añadir cursores en varias líneas, si el editor lo admite.
- **Shift + Alt + ↓:** duplicar una línea o selección en algunos editores.
- **Ctrl + B:** mostrar u ocultar una barra lateral en varias aplicaciones.
- **Ctrl + S:** guardar.

Comprueba el atajo en la aplicación que uses; puede cambiar entre Windows, macOS y editores.

## Administración de programas en Windows

- `winget upgrade`: consultar programas con actualizaciones disponibles.
- `winget upgrade --all`: solicitar la actualización de los paquetes compatibles que administre winget. Revisa la lista y los detalles antes de aceptar cambios.
