# Cómo se construye este contenido

Las guías de esta carpeta nacen de apuntes personales locales. Los archivos fuente `.txt` no se publican ni se modifican como parte de este proyecto.

Cada guía puede incluir tres elementos:

1. ideas nacidas del apunte original;
2. una edición que mejora claridad, estructura y ejemplos;
3. fuentes externas cuando se usan para ampliar o comprobar una recomendación.

No todo el material se convierte en una guía extensa. Las listas personales, como libros y películas, se publican como colecciones curadas; las recomendaciones de salud, empleo o aprendizaje se contrastan antes de presentarse como consejos generales.
