# Cómo se construye este contenido

Las guías de esta carpeta nacen de apuntes personales locales. Los archivos fuente `.txt` no se publican ni se modifican como parte de este proyecto.

Cada documento puede incluir tres elementos:

1. ideas nacidas del apunte original;
2. una edición que mejora claridad, estructura y ejemplos;
3. fuentes externas cuando se usan para ampliar o comprobar una recomendación.

No todo el material se convierte en una guía extensa. Las listas personales, recursos y referencias por confirmar se publican como colecciones; las recomendaciones de salud, finanzas, empleo o aprendizaje se contextualizan antes de presentarse como consejos generales. Los archivos fuente `.txt` son de solo lectura para este flujo editorial: las correcciones se publican en estos documentos Markdown, sin modificar las notas locales.
